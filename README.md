# CorrRaters
Codes and data for the article titled "Bayesian estimation of interrater agreement under the presence of a grey zone and latent correlation between the raters."

The following explains the files and folders in this repository:

cellProbabilities - Folder that includes all the population cell probabilities used in the simulations.
DBDA2E-utilities.R - Utilities functions from Kruschke, John. "Doing Bayesian data analysis: A tutorial with R, JAGS, and Stan." (2014).
findGZFormCellProbs.R - Functions to generate cell probabilities.
generateProbaiblitesUsingSEM.R  - Functions to generate cell probabilities.
generazeGZFormCellProbs.R  - Functions to generate cell probabilities.
ParameterVauesForSims.csv - Parameter values used in the simulations.
TTE_CMRApplication.R - Codes for the application in Section 3.1
physicianPatientApplication.R - Codes for the application in Section 3.2
runModel.R - Scripts to run the proposed model.
runSimulations.R - Scripts to run the simulations.
simulationDriver.csv - Simulation driver file used to run the simulations.
